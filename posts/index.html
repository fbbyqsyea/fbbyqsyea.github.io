        Tmux 详细使用教程#

        什么是 Tmux#

        Tmux（Terminal Multiplexer）是一个终端复用器，允许你在一个终端窗口中管理多个会话、窗口和面板。核心优势：

        • 会话持久化：断开 SSH 连接后任务继续运行，重新连接后可恢复
        • 多面板工作区：单屏幕分割多个终端，并行工作
        • 窗口管理：每个会话可包含多个窗口，类似浏览器的标签页

        安装#

        # Ubuntu/Debian
sudo apt install tmux

# 查看版本
tmux -V
