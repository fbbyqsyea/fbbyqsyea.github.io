    三种交互模式#

    DeepSeek-TUI 提供三种交互模式，分别适用于不同场景。

    Plan 模式 🔍#

    只读探索模式。模型会先提出工作分解方案（通过 update_plan 和 checklist_write），经确认后再执行。

    适用场景：

    • 不确定的重构任务
    • 复杂代码分析
    • 需要理解陌生代码库时
    deepseek  # 默认 Agent 模式
# 在 TUI 中切换到 Plan 模式

    Agent 模式 🤖#

    默认交互模式。支持多步工具调用，每个工具调用前有审批门控。通过 checklist_write 和 update_plan 保持工作可见性。

    适用场景：

    • 日常编码任务
    • 需要逐步确认的操作
    • 大多数编码场景
    deepseek  # 默认即为 Agent 模式

    YOLO 模式 ⚡#

    自动批准所有工具调用，适合可信工作区。仍然使用 checklist_write 和 update_plan 保持操作记录。

    适用场景：

    • 快速原型开发
    • 可信的沙盒环境
    • 不想频繁确认的小改动
    deepseek --yolo  # 启动 YOLO 模式

    模式切换#

    在 TUI 中可以通过快捷键切换模式：

    快捷键功能
    Tab循环模式
    Shift+Tab切换推理强度：off → high → max
    F1 / Ctrl+/可搜索的帮助面板
    Ctrl+K命令面板

    推理强度#

    Shift+Tab 可以在不同推理强度之间切换：

    强度说明
    off不启用额外推理，响应最快
    high高推理强度，适合复杂任务
    max最大推理强度，适合深度分析
