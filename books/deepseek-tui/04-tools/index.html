    工具系统#

    核心工具#

    文件操作#

    工具说明
    read_file读取文件内容
    write_file创建/覆盖文件
    edit_file内联 diff 编辑，提供差异渲染

    Shell 执行#

    shell 工具用于执行 Shell 命令，支持前台和后台执行。每个命令在执行前会显示给请求确认（Agent 模式下）。

    Git 操作#

    内置 git 操作管理，可以执行分支切换、提交、diff 查看等常见 git 命令。

    网络搜索#

    web_search 提供网络搜索能力，Agent 可以查询最新信息。

    子 Agent#

    sub_agents 启动子 Agent 并行处理，适合拆分独立任务。

    工作区回滚#

    DeepSeek-TUI 通过 git 快照实现自动回滚机制：

    • 自动快照：每轮对话前后自动创建快照
    • 隔离仓库：不影响项目本身的 .git 目录
    • 恢复命令：通过 /restore 和 revert_turn 恢复

    这意味着即使 Agent 产生了不想要的修改，也可以轻松回退到之前的状态。

    快捷引用#

    在 TUI 中可以通过特殊语法快速附加上下文：

    语法说明
    @path附加文件或目录到上下文
    /attach <path>附加图片/视频等媒体文件

    提示历史#

    快捷键功能
    Alt+R搜索提示历史并恢复草稿
    Alt+↑编辑最后一条排队的消息
    Tab在生成中时将草稿排队为后续问题
