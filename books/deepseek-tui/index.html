    DeepSeek-TUI 完全指南#

    DeepSeek-TUI 是一个终端原生的编码 Agent，围绕 DeepSeek V4 模型的 100 万 token 上下文窗口 构建。纯 Rust 编写的单二进制文件，无需 Node.js 或 Python 运行时。

    项目地址：https://github.com/Hmbown/DeepSeek-TUI

    章节目录#

    章节标题内容
    01安装与认证预编译安装、Cargo 编译、API Key 配置、环境变量
    02架构设计四层架构、LSP、RLM、Task Queue 子系统
    03三种交互模式Plan、Agent、YOLO 模式，推理强度切换
    04工具系统文件操作、Shell、Git、Web 搜索、子 Agent、工作区回滚
    05Skills 系统技能格式、发现顺序、安装与编写
    06会话管理会话持久化、跨终端恢复、任务队列
    07MCP 支持MCP 服务器配置、常用服务器、验证
    08与 Hermes Agent 对比维度对比、选择建议、互补使用

    快速上手#

    # 1. 安装
npm i -g deepseek-tui

# 2. 认证
deepseek auth set --provider deepseek

# 3. 启动
cd /your/project
deepseek
