    Claude Code 完全指南#

    Anthropic 推出的自主编程智能体 CLI，从安装到进阶使用，全面覆盖。

    核心特性#

    Claude Code 是一个基于命令行的自主编码智能体，能够读取文件、编写代码、执行 Shell 命令、管理 Git 工作流，并在多轮对话中自主规划和迭代。

    特性说明
    自主规划理解任务后自动分解步骤，按顺序执行
    文件操作读取、编辑、创建项目文件
    Shell 集成直接运行命令、测试、构建流程
    Git 工作流自动创建分支、提交、创建 PR
    多轮迭代根据反馈持续优化代码
    子智能体并行委派任务给专用子代理
    MCP 扩展连接数据库、API 等外部服务

    本书结构#

    本指南从安装配置开始，逐步深入各种使用模式和高级技巧。适合从零开始学习 Claude Code 的开发者。
