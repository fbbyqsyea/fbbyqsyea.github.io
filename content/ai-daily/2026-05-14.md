# AI 日报 - 2026年5月14日

## AI最新资讯

- **Anthropic 签 SpaceX Colossus 1 全部算力：22 万颗 GPU + 太空数据中心计划**（5月6日）Anthropic 宣布已签署协议，将在一个月内全面接入 SpaceX 位于孟菲斯的 **Colossus 1** 数据中心，获得超过 **22 万颗 Nvidia GPU** 和 **300 兆瓦**算力。此举旨在应对 Claude Code 在 Q1 实现的 **80 倍**超预期增长（原计划仅 10 倍）。双方还提出联合开发 **多吉瓦级轨道 AI 算力**（太空数据中心）的愿景，利用近恒定太阳能解决地面电力、土地和冷却瓶颈。讽刺的是，Elon Musk 三个月前曾称 Anthropic "邪恶"，如今其 SpaceX 却成为 Anthropic 的关键算力供应商。结合此前 Anthropic 从 Amazon（5GW）、Google + Broadcom（5GW，2027 年交付）、Microsoft Azure（$300 亿）获得的算力承诺，Anthropic 总算力已超 **10 吉瓦**。来源：[xAI](https://x.ai/news/anthropic-compute-partnership)、[Business Insider](https://www.businessinsider.com/anthropic-deal-to-use-elon-musks-colossus-data-center)、[Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/musks-spacex-has-rented-out-access-to-its-supercomputers-220-000-nvidia-gpus-and-300-megawatts-of-ai-compute-power-to-rival-anthropic)

- **Anthropic 联合华尔街五大巨头成立 $15 亿 AI 实施合资公司**（5月4-5日）Anthropic 与 **Blackstone**、**Goldman Sachs**、**Hellman & Friedman**（各出资约 $3 亿）、**Goldman Sachs**（$1.5 亿）及 **Apollo Global Management**、**General Atlantic** 联合成立 $15 亿合资公司。该实体将工程师嵌入中端市场公司（从 PE 投资组合公司开始），围绕 AI Agent 重新设计业务流程，直接解决 AI 人才短缺瓶颈。Goldman Sachs 全球资产与财富管理主管 Marc Nachmann 表示："单有模型不会改变你的工作流——你需要能将技术与实际业务结合的人。"来源：[CNBC](https://www.cnbc.com/2026/05/04/anthropic-goldman-blackstone-ai-venture.html)、[The Next Web](https://thenextweb.com/news/anthropic-15-billion-wall-street-joint-venture)、[Fortune](https://fortune.com/2026/05/05/anthropic-wall-street-financial-services-agents-jamie-dimon/)

- **Anthropic 发布 10 款金融 AI Agent，Jamie Dimon 现场背书**（5月5日）在纽约举办的金融服务业闭门活动中，Anthropic 发布 **10 款金融行业专用 AI Agent**，覆盖银行、保险等领域，可直接接入 Claude Code 和 Cowork 产品。JPMorgan CEO **Jamie Dimon** 与 Anthropic CEO Dario Amodei 同台对话，明确表态 AI 基础设施投资"值得"，并透露 JPMorgan 已有数百个 AI 用例投入生产。Dimon 同时警告 AI 加剧了网络安全风险，成为银行"最大风险"。Anthropic 还在同周宣布与 Google Cloud 达成 **$2000 亿**承诺协议。来源：[Reuters](https://www.reuters.com/business/finance/anthropic-deepens-finance-push-with-10-new-ai-agents-banks-insurers-2026-05-05/)、[American Banker](https://www.americanbanker.com/news/anthropic-launches-bank-friendly-ai-agents-vendor-alliances)、[Axios](https://www.axios.com/2026/05/05/jamie-dimon-ai-capex-anthropic)

- **OpenAI 全面开放 ChatGPT 自助广告平台：支持 CPC 竞价**（5月5-6日）OpenAI 正式推出 ChatGPT **自助式 Ads Manager**（Beta），面向美国广告商开放，支持 **CPC 和 CPM** 两种竞价模式，无最低消费门槛。该平台于 2026 年 2 月启动小范围测试，六周内即实现超 **$1 亿**年化收入。OpenAI 目标今年广告收入 **$25 亿**，到 2030 年达 **$1000 亿**。目前已整合 Dentsu、Omnicom、Publicis、WPP、Adobe、Criteo 等合作伙伴。**Criteo ChatGPT 集成**已有 **1000+ 品牌**上线，AI 引荐转化率接近传统搜索的 **2 倍**，CTR 约高 **3 倍**。来源：[OpenAI 官方](https://openai.com/index/new-ways-to-buy-chatgpt-ads/)、[Axios](https://www.axios.com/2026/05/05/openai-self-serve-ad-platform)、[Search Engine Land](https://searchengineland.com/chatgpt-ads-expand-with-self-serve-buying-476539)

- **纽约时报：OpenAI 与 Anthropic 在华盛顿掀起 AI 游说狂潮**（5月13日）OpenAI 和 Anthropic 正在华盛顿特区开设办公室、雇佣说客并以前所未有的力度影响联邦立法者。Q1 2026 游说支出创历史新高：Anthropic **$160 万**（同比增长 344%），OpenAI **$100 万**（同比增长 78.6%）。Meta 以 **$710 万**仍居科技行业榜首。游说焦点涵盖 AI 政策、国家安全、出口管制和数据中心基础设施建设。来源：[NYT](https://www.nytimes.com/2026/05/13/technology/ai-lobbying-washington-openai-anthropic.html)、[Axios](https://www.axios.com/2026/04/21/anthropic-outspends-openai-biggest-lobbying-quarter)

- **FDA 发布 Elsa 4.0 + HALO 统一数据平台**（5月6日）美国食品药品监督管理局发布内部 AI 工具 **Elsa 4.0** 的重大更新，并与新推出的 **HALO**（Harmonized AI & Lifecycle Operations for Data）平台整合。HALO 将 FDA 跨中心 **40+ 个独立应用、提交数据源和门户**统一为一个平台，使审查人员能在数秒内交叉引用整个提交历史。FDA 强调 Elsa "不对输入数据或受监管行业提交的数据进行训练"，且所有 AI 输出均需人类主题专家验证。FDA 首席 AI 官 Jeremy Walsh 表示："Elsa 即将成为进入 FDA 系统和数据的主要入口。"来源：[FDA 官方](https://www.fda.gov/news-events/press-announcements/fda-expands-ai-capabilities-and-completes-data-platform-consolidation)、[Nextgov](https://www.nextgov.com/artificial-intelligence/2026/05/fda-launches-updated-ai-and-consolidated-data-platform/413370/)、[Hogan Lovells](https://www.hoganlovells.com/en/publications/fda-ai-tool-elsa-40-and-halo-unveiled)

## AI最新算法

- **Anthropic 发布 "Dreaming"（梦境）系统：AI Agent 可自我进化**（*今日重点*，5月6日发布）Anthropic 在 Code with Claude 大会上推出革命性的 **"Dreaming"** 功能——一种在 Agent 空闲时运行的后台记忆管理机制。Dreaming 系统会自动审查记忆库、对话记录和任务结果，执行四项核心操作：(1) 合并跨会话的重复信息；(2) 清除过时/不相关条目；(3) 标记重复模式（反复犯错、已建立的团队偏好）；(4) 重组记忆层以优化未来会话。原始对话记录保持不变，企业在自动批准或手动审核后可部署策展后的记忆。**Dario Amodei 定义**："Dreaming 之前，AI Agent 是工具；Dreaming 之后，AI Agent 是复合资产。"来源：[Anthropic 官方文档](https://platform.claude.com/docs/en/managed-agents/dreams)、[VentureBeat](https://venturebeat.com/technology/anthropic-introduces-dreaming-a-system-that-lets-ai-agents-learn-from-their-own-mistakes)、[Forbes](https://www.forbes.com/sites/jonmarkman/2026/05/11/claudes-new-dreaming-feature-builds-self-improving-ai-agents/)、[Business Insider](https://www.businessinsider.com/anthropic-dreaming-ai-agents-2026-5)

- **Anthropic 多 Agent 编排系统进入公测，Netflix 已部署** 与 Dreaming 同步发布，**Multi-Agent Orchestration** 允许一个主 Agent 将大型任务分解并委派给多个专业子 Agent（每个拥有独立模型、系统提示、工具和上下文窗口）。Netflix 已在其平台团队部署该系统。此外 **Outcomes** 功能允许企业为 Agent 设定明确的成功评估标准。来源：[VentureBeat](https://venturebeat.com/technology/anthropic-introduces-dreaming-a-system-that-lets-ai-agents-learn-from-their-own-mistakes)、[Anthropic](https://claude.com/blog/new-in-claude-managed-agents)

## AI Agent最新进展

- **Anthropic "Dreaming" 重塑 AI Agent 范式**（*与算法部分联动*）Dreaming 系统使 Claude Managed Agent 从"无状态重复工具"转变为"具有长期记忆的自我改进系统"。Dario Amodei 预测 **2026 年将出现首家由单人运营、AI Agent 驱动的十亿美元公司**，并描绘了从"房间里一群聪明人"到"数据中心里的天才国度"的范式转移。Netflix 已在生产环境部署多 Agent 编排。来源：Forbes、VentureBeat

- **AWS AgentCore Payments：AI Agent 可自主执行稳定币微支付** AWS 联合 **Coinbase** 和 **Stripe** 推出 AgentCore Payments 系统，使 AI Agent 能够通过 **x402 协议**自主执行 **USDC 稳定币微支付**，用于 API 调用、数据获取和付费内容解锁。未来将扩展到旅游、电商和商户交易场景。这标志着 AI Agent 从"只能调用免费工具"向"拥有经济自主权"的关键跃迁。来源：MarketingProfs AI Update

- **Anthropic 10 款金融 Agent 定义企业 AI 新范式** 10 款金融行业专用 Agent 覆盖反金融犯罪、风险评估、合规审查等场景，可直接接入 Claude Code 和 Cowork 产品。配合 $15 亿合资公司的嵌入式工程模式，标志着 AI Agent 从通用工具向垂直行业专业化演进。Jamie Dimon 背书表明华尔街已将 AI Agent 视为核心基础设施而非实验性工具。来源：Reuters、American Banker、Fortune
