# AI 日报 - 2026年5月13日

## AI最新资讯

- **Cerebras 今日正式定价 IPO：AI 推理芯片巨头登陆纳斯达克**（*此前曾报道 IPO 提价至 $150-$160，本次为定价日*）AI 推理芯片制造商 Cerebras Systems 于今日（5月13日）正式确定 IPO 发行价，股票代码 `CBRS` 于纳斯达克挂牌。IPO 定价区间此前已从 $115-$125 上调至 **$150-$160**，拟发行 3000 万股，最高募资约 **$48 亿**，有望成为 2026 年至今全球最大 IPO。Cerebras 专注于 AI 推理芯片（与 Nvidia GPU 形成差异化竞争），订单超售 **20 倍**，已获超 **$100 亿**订单承诺。CEO Andrew Feldman 在 IPO 中不减持任何股份，OpenAI 合同价值超 **$200 亿**。来源：[Reuters](https://www.reuters.com/legal/transactional/cerebras-raise-ipo-price-range-150-160-demand-surges-sources-say-2026-05-10/)、[KuCoin](https://www.kucoin.com/news/flash/cerebras-systems-raises-ipo-price-to-150-160-amid-strong-demand)

- **Hugging Face 惊现恶意模型：假冒 OpenAI 项目下载量达 24.4 万次** AI 安全公司 HiddenLayer 发现一个伪装成 OpenAI "Privacy Filter" 项目的恶意 Hugging Face 仓库（`Open-OSS/privacy-filter`），在 18 小时内冲上平台热门榜 **第一名**，累计下载约 **24.4 万次**。该仓库几乎逐字复制了 OpenAI 合法模型卡，但植入了恶意 `loader.py` 文件，在 Windows 系统上执行凭证窃取恶意软件（infostealer），通过 JSON Keeper 作为死投解析器实现动态载荷切换。该事件凸显公共 AI 模型仓库正成为新型软件供应链攻击载体，企业克隆开源模型到内部环境时面临重大安全风险。来源：[BleepingComputer](https://www.bleepingcomputer.com/news/security/fake-openai-repository-on-hugging-face-pushes-infostealer-malware/)、[CSO Online](https://www.csoonline.com/article/4169407/malicious-hugging-face-model-masquerading-as-openai-release-hits-244k-downloads.html)

- **Anthropic Project Glasswing：Claude Mythos Preview 发现 27 年历史级安全漏洞** Anthropic 启动 "Project Glasswing"（玻璃翼蝴蝶计划），将尚未公开发布的旗舰模型 **Claude Mythos Preview** 定向提供给 AWS、Apple、Google、Microsoft、JPMorgan、Cisco 等合作伙伴，用于发现并修复关键基础设施中的零日漏洞。Mythos Preview 已发现**数千个零日漏洞**，包括所有主流操作系统和浏览器中的高危漏洞。其最惊人发现：一个潜伏 **27 年**的 OpenBSD 漏洞（始于 1999 年），以及一个 17 年历史的 FreeBSD 远程代码执行漏洞。Mythos Preview 能在数小时内自主完成安全专家需数天甚至数周才能完成的漏洞利用链构建。Anthropic 因担忧其网络攻击能力可能被滥用，决定**不公开发布**该模型。来源：[Anthropic](https://www.anthropic.com/glasswing)、[The Hacker News](https://thehackernews.com/2026/04/anthropics-claude-mythos-finds.html)、[Simon Willison](https://simonwillison.net/2026/Apr/7/project-glasswing/)

- **Salesforce 推出 Headless 360：CRM 全面转向 API 优先的 Agent 基础设施**（4月15日 TDX 发布，近日持续发酵）Salesforce 发布 **Headless 360**，被其称为"25 年来最大平台变革"——将 Salesforce 全部能力（数据、工作流、业务逻辑）转化为 API、MCP 工具和 CLI 命令，AI Agent 无需通过浏览器 UI 即可直接访问和操作 Salesforce 平台。包含 **60+ 个新 MCP 工具**和 **30+ 预配置编码技能**，可直接接入 Claude Code、Cursor、Codex、Windsurf 等编码 Agent。同时推出 Agentforce Vibes 2.0（多模型 vibe-coding，支持 Claude Sonnet 和 GPT-5）和 Agent Script（确定性 Agent 工作流语言）。这标志着 SaaS 从"人点击界面"向"Agent 直接执行"的范式转移，定价模式也从席位制转向结果导向。来源：[Salesforce](https://www.salesforce.com/news/stories/salesforce-headless-360-announcement/)、[Salesforce Ben](https://www.salesforceben.com/salesforce-headless-360-and-agentforce-vibes-2-0-revealed-at-tdx-2026/)

- **Coinbase 裁员 14%：AI 效率驱动的组织重构** Coinbase 以 AI 技术已使"过去需要团队数周完成的工作现在几天即可交付"为由，裁减约 **14%** 员工。结合此前 Cloudflare 裁员 1,100 人及 >600% AI 使用量增长、Oracle/Snap/IBM 的结构性裁员，AI 驱动的组织重构正从"实验性优化"转变为"人员配置决策的基本参数"。来源：[ToolCrush](https://toolcrush.io/blog/ai-news-may-12-2026)

- **Bain 预测：Agentic AI 自动化将催生 $1000 亿 SaaS 市场** 贝恩公司预测，自主 AI Agent 自动化将催生规模达 **$1000 亿**的 SaaS 市场。企业必须优先构建 Agent 编排、ROI 追踪和工作流集成能力以捕获价值。同时 Google 已将 Agentic AI 治理产品化，但企业采用仍滞后。来源：[AI News](https://www.artificialintelligence-news.com/)

- **Laserfiche 推出 AI Agent 自然语言工作流平台** 企业内容管理平台 Laserfiche 发布新的 AI Agent 功能，支持通过自然语言创建和执行复杂工作流，进一步降低企业自动化门槛。来源：[AI News](https://www.artificialintelligence-news.com/)

- **Microsoft 发布开源 AI Agent 运行时安全工具包** Microsoft 开源了一套用于保护 AI Agent 运行时安全的工具包，帮助企业在部署自主 Agent 时抵御提示注入、工具滥用等安全威胁。来源：[AI News](https://www.artificialintelligence-news.com/)

- **NVIDIA 与 Google 合作降低 AI 推理成本** NVIDIA 与 Google Cloud 联合优化基础设施，显著降低 AI 推理成本。结合前沿级模型输出成本已降至 2024 年 10-20% 的趋势，AI 部署的经济性持续改善。来源：[AI News](https://www.artificialintelligence-news.com/)

- **AI 能量消耗降低 100 倍的新架构突破** ScienceDaily 报道，研究人员开发出一种新架构，在提高 AI 准确性的同时将能量消耗降低 **100 倍**。结合 UCSD 的压电芯片设计（减少 GPU 电源转换浪费），AI 硬件效率正经历代际跃升。来源：[ScienceDaily](https://www.sciencedaily.com/news/computers_math/artificial_intelligence/)
